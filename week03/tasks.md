
# Седмица 3 - Цикли

## Бележки по темата

### Област на променливa (variable scope)

- блок се оформя с къдравите скоби `{}` - всяка отваряща трябва да има съответна затваряща

- областта на една променлива започва от мястото на нейната дефиниция и продължава до края на блока, в който е дефинирана (включително и във вложените блокове).

- локална променлива за блок - променлива, дефинирана в този блок
- нелокална променлива за блок - променлива, дефинирана извън даден блок, но областта и включва блока

    ```c++
    int main() { // блок 1
        int i = 0; // локална за блок 1, нелокална за блок 2
        { // блок 2
            std::cout << i << '\n';
            int i = 10; // локална за блок 2
        }
        std::cout << i << "\n";
    }
    ```

- ако областите на две променливи с едно и също име са вложени една в друга, то локалната променлива скрива нелокалната (variable shadowing)

    ```c++
    int main() { // блок 1
        int i = 0; // локална за блок 1, нелокална за блок 2
        { // блок 2
            int i = 10; // локална за блок 2
            std::cout << i << '\n';
        }
        std::cout << i << "\n";
    }
    ```

- не се компилира програма, която съдържа повече от една дефиниция на локална променлива с едно и също име за даден блок

    ```c++
    int main() { // блок 1
        int i = 0;
        { // блок 2
            i = 10; // каква е тази пр-ва?
            std::cout << i << '\n';
            int i = 20; // локална за блок 2
            {
                std::cout << i << '\n';
            }
            int i = 30; // локална за блок 2
        }
        std::cout << i << "\n";
    }
    
    ```

Какво ще се изведе на стандартния изход във всеки един от горните примери?

### Област на действие на променлива в цикъл

Компилира ли се този фрагмент от код?

```c++
do {
    int i = 0;
    ++i;
} while (i < 10);
```

А какво ще кажете за този фрагмент?
```c++
int i = 0;
do {
    int i = 5;
    ++i;
} while (i < 10);
// само за инфо: има ; след условието в do-while
```

### Оператори `break` и `continue`

- `break` прекратява незабавно изпълнението на цикъла, в който е използван. Ако цикълът е вложен, то външният не се прекратява.
- `continue` прекратява текущата итерация и продължава със следващата.

Примери:
1. Да се провери дали в десетичния запис на положително цяло число се среща четна цифра.
2. Измежду числата от 1 до 50 да се пропусне да се изведат делящите се на 6.
