**Задача 1**  
Ползваме `std::cin` заедно с оператора `>>`, за да прочетем дължините на двете страни на правоъгълника. След това изчисляваме периметъра по формулата `2 * (length + width)`, а лицето — чрез `length * width`. Използваме `double`, за да можем да работим и с нецелочислени дължини.

```cpp
#include <iostream>

int main()
{
    double length, width;
    std::cin >> length >> width;

    double perimeter = 2 * (length + width);
    double area = length * width;

    std::cout << "Perimeter: " << perimeter << '\n';
    std::cout << "Area: " << area << '\n';
}
```

**Задача 2**  
За да разменим стойностите на две променливи, използваме трета променлива, в която временно запазваме стойността на `a`. След това присвояваме стойността на `b` на `a`, а запазената стойност — на `b`.

```cpp
#include <iostream>

int main()
{
    int a = 5;
    int b = 12;

    int temp = a;
    a = b;
    b = temp;

    std::cout << a << ' ' << b << '\n';
}
```

**Бонус**  
Можем да разменим стойностите и без трета променлива, като използваме аритметични операции. Трябва да внимаваме за възможно препълване при събирането на много големи цели числа.

```cpp
#include <iostream>

int main()
{
    int a = 5;
    int b = 12;

    a = a + b;
    b = a - b;
    a = a - b;

    std::cout << a << ' ' << b << '\n';
}
```

**Задача 3**  
За квадратното уравнение `ax^2 + bx + c = 0` първо намираме дискриминантата: `d = b * b - 4 * a * c`. 
Хубаво е да проверим дали дискирминантата не е по-малка или равна на 0, но все още не сме взели if.
Също ще е хубаво да проверим дали потребителя не е въвел `a = 0`, защото иначе ще имаме делене на 0,
но за сегашните ни знания можем да приемем, че уравнението си е квадратно и има 2 реални корена. Функцията `std::sqrt()` намира квадратния корен и е от библиотеката `<cmath>`.

```cpp
#include <iostream>
#include <cmath>

int main()
{
    double a, b, c;
    std::cin >> a >> b >> c;

    double d = b * b - 4 * a * c;

    double x1 = (-b - std::sqrt(d)) / (2 * a);
    double x2 = (-b + std::sqrt(d)) / (2 * a);

    std::cout << "x1 = " << x1 << '\n';
    std::cout << "x2 = " << x2 << '\n';
}
```

**Задача 4**  
С операцията `number % 10` вземаме остатъка при деление на `number` на 10. При положително цяло число това ни дава последната цифра. След това с `number /= 10` премахваме последната цифра, защото при целочислено деление се запазва само цялата част от резултата. Редувайки тези две операции, можем да извлечем цифрите на трицифреното число и да ги съберем.

```cpp
#include <iostream>

int main()
{
    int number;
    std::cin >> number;

    int lastDigit = number % 10;
    number /= 10;

    int secondDigit = number % 10;
    number /= 10;

    int firstDigit = number % 10;

    int digitsSum = firstDigit + secondDigit + lastDigit;

    std::cout << digitsSum << '\n';
}
```

**Задача 5**  
Първо намираме абсолютната стойност на `x` с `std::fabs()`. Търсим най-малкото положително цяло число, което е **строго по-голямо** от тази стойност.
Използваме `std::floor(absX) + 1`. Функцията `std::floor()` закръгля надолу до най-близкото цяло число, а прибавянето на единица гарантира, че резултатът е по-голям дори когато `absX` вече е цяло число.
Може да се използва и `std::ceil(absX)`, вместо `std::floor(absX) + 1`,
но тогава, ако е подадено цяло число, резултатът ще е равен на абсолютната стойност, а не строго по-голям. 

```cpp
#include <iostream>
#include <cmath>

int main()
{
    double x;
    std::cin >> x;

    double absX = std::fabs(x);
    double result = std::floor(absX) + 1;

    std::cout << result << '\n';
}
```

**Задача 6**  
За да намерим разстоянието между две точки `A(x1, y1)` и `B(x2, y2)`, използваме формулата:

$$
d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}
$$

Функцията `std::pow()` повдига число на степен, а `std::sqrt()` намира квадратния корен. И двете функции са от библиотеката `<cmath>`.

```cpp
#include <iostream>
#include <cmath>

int main()
{
    double x1, y1, x2, y2;
    std::cin >> x1 >> y1 >> x2 >> y2;

    double distance = std::sqrt(
        std::pow(x2 - x1, 2) +
        std::pow(y2 - y1, 2)
    );

    std::cout << distance << '\n';
}
```
