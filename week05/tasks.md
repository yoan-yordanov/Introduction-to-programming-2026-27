## Задачи

**Задача 0**

Разгледайте задача 12 от седмица 4. Тогава я решихме само в main. Сега разделете задачата на подзадачи, за които напишете отделни функции.

**Задача 1**

Напишете функция, която приема параметри две числа и връща резултата от първото число, повдигнато на степен второто.

Вход:
```
2 5
```

Изход:
```
32
```

**Задача 2**

Напишете функция, която приема параметър цяло число и връща дължината му (броя на цифрите му).

| Вход | Изход |
|:---|:---|
| 12345 | 5 |
| -123 | 3 |
| 0 | 1 |

**Задача 3**

Напишете функция, която приема параметри две естествени числа и връща тяхната конкатенация (число, а не низ!).

| Вход | Изход |
|:---|:---|
| 12 345 | 12345 |
| 100 0 | 1000 |


**Задача 4**

Напишете функция, която проверява дали двоичният запис на подадено положително число е палиндром.

| Вход | Изход |
|:---|:---|
| 9 | true |
| 10 | false |
| 15 | true |
| 21 | true |
| 1234 | false |

*Насока*: 
- дефинирайте функция convertToBinary, която преобразува десетично до двоично число
- дефинирайте функция reverseNumber, която обръща цифрите на число

*Внимание*: Ако ви минава теста при вход 1234, няма гаранция, че програмата е вярна. Уверете се, че при вход 1234 convertToBinary връща очаквания резултат.

**Задача 5**

Напишете функции, които приемат параметри две числа и връщат резултата от делението им. Трябва да работят с `double` и с `int` и да са с еднакви имена (function overloading).

**Задача 6**

Напишете функция `isPerfect`, която приема положително цяло число и проверява дали то е равно на сумата на своите положителни делители, различни от самото него.

| Вход | Изход |
|:---|:---|
| 6 | true |
| 28 | true |
| 12 | false |
| 496 | true |

**Задача 7**

Напишете функция `printPerfectNumbers`, която приема две цели числа `a` и `b` и извежда всички съвършени числа в интервала `[a, b]`.

Вход:
```
1 1000
```

Изход:
```
6 28 496
```

**Задача 8**

Напишете функция `removeDigit(int number, int digit)`, която премахва всички срещания на дадена цифра от числото и връща полученото число.

Вход:
```
123456 3
```

Изход:
```
12456
```

**Задача 9**

Напишете функция `largestAfterRemovingDigit(int number)`, която намира най-голямото възможно число, получено чрез премахване на всички срещания на една избрана цифра от числото.

Вход:
```
123456
```

Изход:
```
23456
```

**Задача 10**

Въвеждат се от стандартния вход неотрицателни числа до въвеждане на `-1`. Да се намери най-големият общ делител на тези числа.

Вход:
```
24 36 60 12 -1
```

Изход:
```
12
```
