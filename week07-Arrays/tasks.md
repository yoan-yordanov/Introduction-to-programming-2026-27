# Седмица 6 - Масиви

## Бележки по темата

### Дефиниция

- непрекъсната последователност от елементи от един и същи тип

### Дефиниране на масив

- размерът на масива e неотрицателно цяло число

    ```c++
    const unsigned SIZE = 5;
    // constexpr unsigned SIZE = 5;
    int arr[SIZE];
    ```
- constexpr задължава дясната част на присвояването да бъде пресметната още по време на компилация
- const позволява дясната част да бъде изчислена и по време на изпълнение
- една константа веднъж инициализирана не може се променя

    ```c++
    #include <iostream>

    unsigned getSize() { return 10; }

    int main() {
        const unsigned SIZE = getSize(); 
        //constexpr unsigned SIZE = getSize(); // not compile
        int arr[SIZE];
        SIZE = 20; // error
        return 0;
    }
    ```

- някои компилатори позволяват размерът да бъде променлива (вкл. да го подадем от конзолата и да дефинираме масив), но тази възможност не е част от стандартния c++ и съответно в курса не е разрешено да се ползва.

### Дефиниция на масив с инициализация

- размерът отново е константа
- размерът може да бъде по-голям от броя на елементите в дясната част - останалите са нули
    ```c++
    const unsigned SIZE = 5;
    int arr[SIZE] = { 1, 2, 3, 4, 5 };
    ```
- при дефиниция с инициализация може да изпуснем размера на масива, но е добре да се пише явно

    ```c++
    int arr[] = { 1, 2, 3, 4, 5 };
    const unsigned SIZE = sizeof(arr) / sizeof(arr[0]); // true only in this function
    ```
- вярно САМО във функцията, в която `arr` е дефинирано

### Достъп до елементите на масив и операции върху тях

- елементите се достъпват чрез индекси от `0` до `SIZE - 1`

    ```c++
    const unsigned SIZE = 5;
        int arr[SIZE] = { 1, 2, 3, 4, 5 };
        std::cout << arr[0] << '\n'; // 1
        arr[4] = arr[4] * 2;
        std::cout << arr[4] << '\n'; // 10
    ```

### Примери

1) Да се дефинира масив от цели числа с размер 5, да се въведат 5 цели числа от терминала и да се съхранят в масива.

2) Да се дефинира масив с инициализация и да се принтира размера му. 

3) Създайте масив с един от горните начина и изпълнете следните задачки:
    - да се принтират само четните елементи / положителните числа
    - да се провери дали масивът дали образува строго намаляваща редица
### Подаване на масив като параметър на функция

- винаги масив се подава във функция с неговия размер

    ```c++
    void printArray(int arr[], unsigned size) {
        //unsigned size = sizeof(arr) / sizeof(arr[0]); wrong
        for (unsigned i = 0; i < size; ++i) {
            std::cout << arr[i] << ' ';
        }
        std::cout << '\n';
    }
    ```
- закоментираният ред не работи, защото `arr` като параметър във функция е указател към първия елемент в масива. Всъщност `sizeof(arr)` връща размера на указателя, а не на целия масив, но за указатели по-късно.

- промени върху елементите, извършени във функция, се отразяват върху масива в извикващата функция
- ако не искаме да променяме елементите: `int func(const int arr[], unsigned size)`
