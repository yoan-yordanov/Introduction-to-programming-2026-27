# Задачи

Задача 1: Напишете програма, която чете от конзолата 2 числа - дължините на двете страни на правоъгълник. Да се изведе неговите периметър и лице в конзолата.

Вход:

    4 3
    

Изход:

    Perimeter: 14
    Area: 12
    

Задача 2: Напишете програма, която да разменя стойността на две променливи, съдържащи цели числа.

    int a = 5;
    int b = 12;

    //your code here

    std::cout << a << ' ' << b << '\n';

Изход:

    12 5
    

**Бонус:** Опитайте се да го направите без да използвате трета променлива.

Задача 3: Да се въведат от конзолата коефициенти за квадратното уравнение `ax^2 + bx + c = 0`. Да се изведат корените на уравнението.

Вход:

    1 -5 6
    

Изход:

    x1 = 2
    x2 = 3
    

Задача 4: Напишете програма, която прочита 3-цифрено число от конзолата и принтира сбора на 3-те цифри, от които е съставено.

Вход:

    123
    

Изход:

    6

Задача 5: Да се прочете едно число с плаваща запетая X и да се изведе на екрана най-малкото положително цяло число, което е по-голямо от абсолютната стойност на X.

Вход:

    -4.3
    

Изход:

    5
    

Задача 6: По дадени координати на две точки да се изведе разстоянието между тях.

Вход:

    0 0
    3 4
    

Изход:

    5
