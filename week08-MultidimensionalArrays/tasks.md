# Седмица 8 - Многомерни масиви

## Бележки по темата

### Дефиниране

- двумерен масив - масив от елементи от тип едномерен масив
- логически може да си мислим за двумерния масив като таблица, но физически в паметта редовете на двумерния масив са разположени последователно един след друг.

### Дефиниция с инициализация

- задължително се указва броят на колоните
    ```c++
    const unsigned numRows = 2;
    const unsigned numCols = 3;
    int matrix[numRows][numCols] = { { 1, 2, 3}, { 3, 4, 5} };
    ```
### Дефиниция на двумерен масив с размери от стандартния вход

- заделя се повече място от колкото ни трябва

    ```c++
    #include <iostream>

    const unsigned MAX_SIZE = 10;

    int main() {
        unsigned numRows, numCols;
        std::cin >> numRows >> numCols;
        int matrix[MAX_SIZE][MAX_SIZE];
        for (unsigned i = 0; i < numRows; ++i) {
            for (unsigned j = 0; j < numCols; ++j) {
                std::cin >> matrix[i][j];
            }
        }
        return 0;
    }
    ```

### Подаване на двумерен масив във функция

- изнасяме максималния размер на матрицата в глобална константа
- При подаване на двумерен масив във функция задължително се указва размерът на колоните `MAX_SIZE`. В паметта редовете на двумерния масив са разположени последователно един след друг като един линеен масив `arr`, затова компилаторът пресмята достъпа до елемент като:
`matrix[i][j] = arr[i * MAX_SIZE + j]`.
За да знае с колко позиции да „прескочи“ за всеки следващ ред (отместването), му е необходим броят на колоните.

    ```c++
    #include <iostream>

    const unsigned MAX_SIZE = 100;

    void printMatrix(int matrix[][MAX_SIZE], unsigned numRows, unsigned numCols) {
        for (unsigned i = 0; i < numRows; ++i) {
            for (unsigned j = 0; j <  numCols; ++j) {
                std::cout << matrix[i][j] << ' ';
            }
            std::cout << '\n';
        }
    }

    int main() {
        unsigned numRows, numCols;
        std::cin >> numRows >> numCols; // добре е да валидирате входните данни, не трябва да бъдат повече от MAX_SIZE
        int matrix[MAX_SIZE][MAX_SIZE];
        for (unsigned i = 0; i < numRows; ++i) {
            for (unsigned j = 0; j < numCols; ++j) {
                std::cin >> matrix[i][j];
            }
        }
        printMatrix(matrix, numRows, numCols);
        return 0;
    }
    ```
- за двумерен масив, дефиниран с инициализация, също се дефинира поне една глобална константа за брой колони, ако искаме да подадем масива във функция
