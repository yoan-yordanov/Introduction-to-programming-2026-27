Visual Studio Code:

Основни стъпки:

## Работа с терминал (powershell)

1. Отваряне на терминал - Ctrl + `
- ако сме отворили папка mydir във VS Code, в терминала ще се намираме точно в тази папка.

2. Основни команди
- cd \<dir_name\> - преместване в \<dir_name\>
- ls \<dir_name\> - извежда информация за файловете в \<dir_name\> 

3. Специални директории
- родителска директория (..)
- текуща директория (.)

4. Примери
- cd mydir - от текущата директория се преместваме в mydir 
- cd .. - връщаме се към родителя на текущата директория
- ls . - извежда инфо за текущата директория (точката може да се пропусне)
- cd ../mydir - връщаме се една дир назад и отиваме в mydir

Съвет: отворете терминал и се разходете из файловата система
